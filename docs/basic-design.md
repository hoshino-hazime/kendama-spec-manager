# 1ヵ月目成果物：基本設計書

## 1. 画面設計・UI

### 1-1. 画面構成
1. **セッティング一覧画面（トップ画面）**
   * 現在ペアリングされている「玉＋けん」のセット一覧を表示。
   * 新規セット作成、組み合わせの変更（編集）、セット解除（削除）。
2. **玉 一覧画面**
   * 所持している玉の一覧表示、新規登録、編集、削除。
3. **けん 一覧画面**
   * 所持しているけんの一覧表示、新規登録、編集、削除。

### 1-2. 画面レイアウト構成（ワイヤーフレーム）
手書きUIスケッチに基づく基本配置構成：

* **ヘッダー部:** アプリタイトル、他画面へのリンク
* **コントロール部:** 検索バー、状態絞り込み、新規登録ボタン
* **データ表示部:** パーツ・セット情報の表示（写真、スペック、状態）
* **アクション部:** 編集ボタン、削除ボタン

※初期UI手書きスケッチはリポジトリ内の画像を参照。
---

## 2. 機能設計 (CRUD)

* **玉・けん　管理機能:** 新規登録(C)、一覧・詳細取得(R)、スペック修正(U)、データ削除(D)
* **ペアリング機能:** 玉とけんを紐付けてセットを作成(C)、一覧取得(R)、ペア組み替え(U)、セット解体(D)
* **検索・絞り込み機能:** キーワード検索、ステータス別フィルタリング
