# けん玉コレクション管理(Kendama Spec Manager)

けん玉の「玉」と「けん」の重量・状態を個別に記録し、また現在のセッティングを管理するためのWebアプリケーションです。

---

## 1. 開発動機
* **重量・個体差の管理:** けん玉は「玉」や「けん（けん軸・皿胴）」の重量バランスが技のやりやすさに直結しますが、所持数が増えると個体ごとのスペック把握が困難になります。
* **組み替えへの対応:** 消耗や好みに応じて「お気に入りの玉」を「別のけん」に移植することが多いため、「今どのパーツ同士が組み合わさっているか」を一目で把握できる仕組みを目指します。
* **状態の整理:** 「新品」「使用中」「破損」「記念保存」「譲渡」などの状態を可視化します。

---

## 2. 管理対象データ
1. **玉 (Tama)**
   * メーカー名、モデル名、重さ(g)、状態、写真、メモ
2. **けん (Ken)**
   * メーカー名、モデル名、けん全体の重さ(g) [必須]
   * けん軸の重さ(g)、皿胴の重さ(g) [任意]
   * 状態、写真、メモ
3. **現在のセッティング (Setup)**
   * 登録済みの「玉」と「けん」を組み合わせたペア

---

## 3. 機能要件 (CRUD一覧)
* **玉の管理:** 登録(Create) / 一覧・詳細参照(Read) / 更新(Update) / 削除(Delete)
* **けんの管理:** 登録(Create) / 一覧・詳細参照(Read) / 更新(Update) / 削除(Delete)
* **セッティング管理:** ペアリング登録(Create) / 現在のセット一覧表示(Read) / 組み替え更新(Update) / ペア解除(Delete)
* **絞り込み機能:** 重量帯や状態ステータスによる検索
